# Customer Churn Prediction Machine Learning Pipeline

An end-to-end machine learning project designed to predict customer churn for subscription-based businesses using behavioral and account data.

## 🚀 Project Overview
Customer churn is a critical metric for subscription businesses. This project builds a classification model to identify high-risk customers, allowing retention teams to intervene proactively.

## 📊 Dataset Features
The model evaluates the following features:
- **tenure_months**: How long the customer has stayed with the company.
- **monthly_charges**: The amount charged to the customer monthly.
- **total_charges**: Total cumulative amount charged.
- **support_tickets**: Number of customer support issues raised.
- **contract_type**: Length of the customer contract (Month-to-month, 1-year, 2-year).
- **is_senior**: Demographic indicator.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Scikit-Learn, Joblib
